## Source and attribution

The Medea visual identity is project-specific artwork developed with AI image-generation assistance and curated by the repository maintainer for this open-source project. It is **not** the Alpaca logo, and neither this imagery nor this project implies endorsement by or affiliation with Alpaca Markets. The branding assets are separate from Alpaca's trademarks.

The original generated assets were committed to `docs/` for traceability, and are not replaced by optimized copies. The README uses `docs/fancy.webp` for a lightweight, responsive display; `docs/fancy.png` is the full-resolution source banner.

## GitHub repository social preview

GitHub repository **Settings → General → Social preview → Edit → Upload image** is a **manual maintainer step**; a README image by itself does not set the link-preview image. Use `docs/fancy.png` as the candidate, review GitHub's crop so the wordmark is legible, then save the preview. If GitHub requires a 2:1 composition, prepare a separate cropped/padded copy while retaining `fancy.png` as the source.

- Settings: https://github.com/black-belt-badger/medea/settings
- Preview check: share the repository URL or inspect GitHub's `openGraphImageUrl` GraphQL field. The default autogenerated image typically uses `opengraph.githubassets.com`; custom uploads use GitHub's repository-image hosting.
- Do not confuse the *repository social preview* with the organization/avatar image or the README banner. They are separate settings.

## Verification

The README embeds its banner at a constrained width of 760 pixels and GitHub's Markdown viewer scales it for narrower screens. Its image paths are relative and the text remains legible without images thanks to descriptive alt text. Preview the page and its icon in GitHub light and dark themes and at phone width when completing the manual social-preview step.

This documentation-only asset guide does not alter API behavior. CI badges and project code remain unchanged.
