Medea is an **unofficial, read-only Rust CLI** for Alpaca **paper trading accounts**, developed alongside the Haskell [Kirke](https://github.com/black-belt-badger/kirke) application. This is the first **prerelease**, not a stable API or a live trading tool.

### Features

- `medea account`: display account number, status, currency, cash, equity, buying power, trading block status, and optional crypto status.
- `medea account --out PATH`: save the validated complete, unmodified JSON to an owner-only file using atomic replacement.
- Credentials from environment variables `APCA_API_KEY_ID` and `APCA_API_SECRET_KEY`.
- Paper-only HTTPS endpoint, 20-second timeout, redirects disabled, safe error messages, and exact preservation of monetary decimal strings.
- 31 offline unit and CLI tests; opt-in real paper-API verification script.

### Build and install on Linux

Requires Rust **1.99.1** via rustup.

```sh
git clone https://github.com/black-belt-badger/medea.git
cd medea
git checkout v0.1.0
./scripts/ci.sh
medea --help
```

`scripts/ci.sh` runs formatting, Clippy, tests, an optimized release build, and `cargo install` into your Cargo user binary directory (usually `~/.cargo/bin`). Add that directory to `PATH` if necessary. Source archives are provided by GitHub; this release does not bundle platform-specific executables.

For authenticated operations, set **paper** credentials in the environment; see [README.md](https://github.com/black-belt-badger/medea/blob/v0.1.0/README.md) for a private credentials-file example. Keep JSON files and account summaries private.

### Scope and limitations

Only `GET /v2/account` on Alpaca's **paper** API is implemented. There are no live trading, order placement, market data, streaming, or installation packages yet. This version is not affiliated with or endorsed by Alpaca Markets.
