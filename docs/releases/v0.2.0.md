# Medea v0.2.0 — Trading state and historical crypto data

**Medea** is an unofficial, read-only Rust command-line client for Alpaca's paper Trading API and Crypto Market Data API, developed alongside [Kirke](https://github.com/black-belt-badger/kirke) in Haskell. This is a public **prerelease**; interfaces may change before 1.0.

## What's new since v0.1.0

- **Paper account state:** `medea positions` lists open crypto/equity positions; `medea assets` discovers assets with class/status filters.
- **Order inspection:** `medea orders` filters paper order history; `medea order get ORDER_ID` retrieves an order by validated UUID, optionally including nested legs. These are all read-only.
- **Historical crypto bars:** `medea crypto bars` fetches typed OHLCV data using symbols, timeframe, location, date bounds, sort, and bounded page-token pagination.
- **Historical crypto trades:** `medea crypto trades` fetches individual executions using precise integer trade IDs and decimal prices/sizes, nanosecond timestamp strings, and optional taker-side field. It processes one page at a time without retaining the whole history.
- **Exports:** readable summaries, complete JSON page envelopes with continuation tokens, and per-symbol JSONL records. Private output is atomic; failures on a later page preserve existing files.
- **Docs and identity:** README branding, optimized logo images, an integration script for maintainers, and clearer security and contribution documentation.

## Example commands

```sh
mkdir -p output
chmod 700 output
medea account
medea positions --out output/positions.json
medea assets --status active
medea orders --status all --limit 10
medea crypto bars --symbols BTC/USD,ETH/USD --timeframe 1Hour --max-pages 2 --out output/bars.json
medea crypto trades --symbols BTC/USD,ETH/USD --max-pages 2 --format jsonl --out output/trades.jsonl
```

## Build and install (source distribution)

Requires **Rust 1.99.1**, pinned in `rust-toolchain.toml`, and a compatible Unix-like system.

```sh
git clone https://github.com/black-belt-badger/medea.git
cd medea
git checkout v0.2.0
./scripts/ci.sh
medea --help
```

The script formats/checks the code, runs Clippy and tests, builds a release binary, and installs the CLI locally. See the [README](https://github.com/black-belt-badger/medea/blob/v0.2.0/README.md) for credential setup and all CLI flags. Supply `APCA_API_KEY_ID` and `APCA_API_SECRET_KEY` through environment variables.

## Safety, limitations, and distribution

- Paper Trading API for account/order **reads** and Crypto Market Data API for historical bars/trades. **No live trading, order placement/cancellation, historical crypto quotes, or real-time streaming.**
- Bounded pagination; JSONL stdout can have partial output after a later failure, while atomic `--out` files are all-or-nothing. JSONL does not include a resume token.
- GitHub provides source archives, not prebuilt platform-specific binaries. No crates.io publication in this release.
- Medea is **unofficial**, not affiliated with or endorsed by Alpaca Markets.
